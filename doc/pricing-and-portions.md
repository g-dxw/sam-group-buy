# 商品定价与按份拼单

[返回项目首页](../README.md) · [文档目录](README.md)

## 商品原价与售价

商品库单独保存采购参考原价、定价规则与最终售价。原价来自山姆查询记录，也可手动补填或校正；原始采集价、门店和查询时间仍保留。定价可选择按比例加价，或固定金额加价：比例为 0% 至 1000%，金额为非负数，都最多两位小数。售价分别为“原价 ×（1 + 加价比例）”或“原价 + 加价金额”；例如原价 100 元，固定加价 5 元，售价为 105 元。金额以整数分计算，比例结果四舍五入到分；0% 或加价 0 元均表示按原价销售。两种加价方式都需要原价，新选山姆商品默认加价 0%。

旧版固定售价继续保留已有金额。编辑旧商品时，有原价且售价不低于原价的商品会按差额预填固定加价金额，保存后才采用新规则；缺原价或旧售价低于原价的商品可先沿用现有售价编辑其他资料，补齐原价后再选择加价方式。客户历史订单不会随规则转换变化。

勾选商品后可“批量定价”，选择统一的加价比例或固定加价金额，按每件原价分别计算，先预览再确认。重复应用同一规则仍以原价计算，不在已有售价上累加。预览绑定商品版本，原价、售价或资料在确认前变化时需重新预览；缺价商品会阻止整批调价。刷新山姆原价只查询商品来源绑定的门店与 SPU，不直接保存；使用查询结果并保存后，按比例商品沿用比例重算售价，固定加价商品沿用加价金额重算售价，尚未转换规则的旧固定售价保持不变。

定价仅作用于后续订单；升级前无单价快照的旧明细按升级前当前金额固定。本期代购费单独按售价金额及活动当前费率计算，调整活动费率会立即重算已有订单，售价已包含加价时可把推荐代购费设为 0%。分装售价按整包售价预填后独立保存，商品库调价不覆盖本期每份售价，也不再次加价。后台分装采购显示原包装参考原价；缺原价或旧明细仅有售价时明确标注售价参考。客户只看到售价和费用明细，不公开原价及加价规则。

飞书商品备份保留“单价”为最终售价，并增加唯一文本字段“定价规则”，以 JSON 完整保存参考原价与定价方式。字段在正常备份流程补齐，完整读回后才确认已备份。

## 按份拼单

在“团购期次 → 新建一期 / 编辑本期”中，为本期选中的商品开启“按份拼单”，填写每包拆分份数、每份规格和每份售价。默认仍是整包购买；分装是期次配置，不改变商品库中的原包装资料。客户卡片显示每份价格与分装规格，购买数量以份计；同款山姆搜索结果明确显示分装规格。旧的整包个人清单不会自动转换成份数，需要重新选择本期商品。

已有该商品订单后，售卖方式、每包份数与每份规格锁定；每份售价可以调整，影响后续新订单。新单冻结每份价格、原包装资料和收费类别，代购费按本期最新费率重算。报价中的分装金额属于预计金额，下单后未确认成团的商品款和代购费不进入应付账单，客户订单会单独显示待拼金额。

收集结束后到“订单统计”确认分装采购。系统按下单时间和明细编号依次分配：每凑满 N 份采购一包，选择“余份不采购”时不足整包的部分标为未成团、不收费；选择“补齐余份”时向上取整采购，你承担未被客户报名的剩余份数。一次购买多份可能部分成团。确认结果事务保存，重复点击不会重复采购或分配；确认后禁止继续向该商品下单和修改订单份数，可以继续处理采购状态、缺货或取消，已确认分配不会重新排序。

客户账单只计算有效成团份数，并按本期最新费率计算代购费。后台采购清单展示原包装包数和采购参考金额，客户分货清单展示成团份数；原包装采购参考金额与客户应付金额是不同用途。已确认后发生取消、缺货，客户不收费，已确定采购包数保留，剩余份数由你处理。

新建的群订单表自动包含唯一 text 字段“同步拼份信息”，保存规则、每份报价与确认分配的 JSON。旧表核查或后续字段被修改时，缺少或类型不匹配会明确阻止相应备份，仍保留本地订单。完整的期次配置和采购确认以本地数据库及全量备份为准。

代购费分组、舍入和飞书字段规则见[飞书备份 → 同步规则](feishu.md#同步规则)。
