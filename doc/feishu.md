## 飞书配置

后台“飞书备份”会带入当前备份目标。粘贴飞书多维表格的 Base 链接，点击“读取数据表”，选择共用商品备份表与历史订单表，再检查连接并保存。历史订单表用于保留旧备份和未确认同步的核查；新订单按群同步到独立数据表。也可在高级设置中填写 Base token 和数据表 ID。配置保存到 SQLite，重启后保留。

连接检查读取多维表格和字段结构，验证商品必需列、订单同步列及状态选项；读取成功不代表已经验证写入权限。飞书用户授权继续使用运行服务器上的 lark-cli，网页不接收应用密钥或访问令牌。授权失效时在服务器重新授权，回来检查连接。

保存配置不会自动写入商品、订单或创建群表。更换商品备份目标后，商品标为待备份；到“商品库”手动备份。商品 ID 必须继续代表同一商品。同一个 Base 内更换历史订单参考表，不会重置各群订单表或已同步记录。更换 Base 后，各群在新 Base 首次手动同步时建立或复用自己的表，逐期核对后切换，原飞书数据和旧目标归属保留。如果旧目标还有无法确认的写入，系统要求先完成核查再切换。同步进行期间不能更换配置。

需要补齐新版订单同步字段时，`npm run setup:admin` 使用数据库中的当前配置。目标表仍需符合现有商品和订单字段结构；页面会列出缺失或类型不兼容的字段，检查失败不覆盖当前配置。

## 同步规则

本地商品 ID 是固定匹配键，选品使用 `sam_<山姆SPU>`；SPU 不代表所有规格的 SKU，也不代表全国门店全量商品。查询返回所选门店的官方榜单或关键词搜索结果，库存与价格可能变化。官方榜单支持不输入关键词浏览和分页；榜单及其中的分类来自上游公开入口，覆盖部分商品，不是完整商品分类树或全门店目录，榜单分类也不会自动当成本地商品分类。价格读取销售价类型 1，以整数分保存；无有效价格或图片的商品不能入库。来源保存城市、门店、关键词或榜单及榜单分类、查询时间、原始采集价和图片地址；后台售价修改后，原始采集价仍保留供核对。

商品备份按商品 ID 新增或更新同一记录，不删除飞书中的其他商品。首次备份旧的 8 列商品表时自动补齐“图片地址”“来源数据”“数据版本”“更新时间”“定价规则”“移除时间”6 列；已有字段类型不兼容时停止。已移除商品仍参与备份，记录为下架状态并保存移除时间。新增结果不明确时先核对，禁止盲目重复新增；完整读回后才标为已备份。备份途中又改商品会保留待备份状态。飞书的编辑、删行或离线不会自动修改本地商品。

新订单保存顾客确认时的商品单价、收费类别与下单时的费率记录。商品单价和收费类别保留，已有订单的代购费按活动当前推荐或自选费率重算。升级前未保存快照的历史推荐订单在定价功能迁移时固定升级前当前价格；已有订单与新单一样采用活动当前费率。配送费仍不在系统内计算。

每期可设置推荐商品代购费率和独立自选费率，支持 0% 至 100%、最多两位小数；自选费率为空时跟随推荐费率，两种费率不叠加。修改费率立即重算本期已有订单，并将费率或费用变化的明细标为待备份，包括费用仍为 0 的明细。费用按同一期次、同一手机号、原收费类别和当前费率分组，先合并有效商品金额再四舍五入到分。缺货和取消项不收费；追加和数量调整会重新计算有效金额，并将费用分摊变动的明细标为待备份。客户购物车由只读报价接口核对本次追加的商品额、代购费增量和应付金额；价格、收费规则或既有订单发生变化时需要重新确认。相同提交编号的重试沿用原订单，不重复收费。

订单数据库为准，修改统一在网页后台进行；飞书用于同步后的统计、采购。每个小区或群在同一个 Base 中绑定一张独立的“群名称 · 下单明细”表，同群各期继续建立独立视图。商品备份表共用。首次手动同步自动创建包含普通订单、收费和拼份快照字段的群表，后续期次复用；按固定群编号绑定，不根据相似名称混用其他群的表。建表结果不明确时先核对，不盲目重复建表。

旧总表保持不变。首次同步历史期次时，仅该期切换到所属群表，本地保留旧目标与记录绑定归档，其他群和期次不会一起重置。若旧总表存在未确认新增，先对旧目标核对，确认后再切换；无法确认时保留标记并提示待核查。每条明细有固定编号，重复同步按编号更新。新增请求结果不明确时先对账，不盲目再次创建；部分失败保留待同步。同步期间又编辑的明细不会被误标已同步。采购前请确认本期没有遗漏的待同步项。

飞书导出携带小区、期次、已确认商品资料、单价与商品金额。「同步金额」保持商品金额含义，采购清单只列真实商品。新群表自动包含唯一字段：「同步代购费」number、「同步代购费率」number（1 表示 1%）、「同步收费类别」text、「同步应付金额」number，以及「同步拼份信息」text。旧表核查或后续字段被修改时，缺失或类型错误会明确阻止相应订单备份。本地订单保留，费用字段严格读回核对后才确认完成。后台专用视图使用同步字段统计，避免未同步的飞书价格与网页金额混用。下单成功表示清单已保存，付款独立确认。

飞书不能代替完整数据库备份。数据库备份和授权维护见[本地运行与维护](maintenance.md)。
