# 使用指南

[返回项目首页](../README.md) · [文档目录](README.md)

命令均在项目根目录执行。定价和拼份规则见[商品定价与按份拼单](pricing-and-portions.md)，飞书配置与导出见[飞书备份](feishu.md)。

## 每次团购怎么操作

1. 后台“山姆选品”选择城市和门店，可直接点官方榜单浏览商品，或切换到“搜索商品”输入关键词，查看图片与销售价格，勾选后点击“加入商品库”。可分页选择，查询结果在服务器保存 30 分钟，过期或重启后需重新查询。
2. 在“商品库”核对名称、规格、单位和售价，再上架。分类暂时不在界面展示。上架保存商品的销售状态；如果期次已经建立，新商品还要到“团购期次 → 编辑本期 → 本期商品”加入该期，保存设置后顾客页才会展示。可用“追加新上架商品”带入新商品并保留原选择。新商品默认待上架；重复选同一山姆 SPU 只跳过，不覆盖已有售价、图片或上架状态。需要留存到飞书时点击“同步到飞书备份”。
3. 在“团购期次”选择小区或群，首次可新增小区。“新建一期”自动接着编号第 1、2、3 期，默认带入当前在售商品，可调整范围并填写截止、取货说明。在“本期采购门店”选定城市和门店，保存后开启顾客自选；清空门店关闭自选，已有推荐商品仍可下单。
4. 复制本期专属链接或下载二维码，发到对应群。顾客页面自动显示小区和期次。
5. 打开该期订单，按商品查看采购汇总，按手机号查看分货名单；可改数量、处理状态或取消某件商品。
6. 点击“同步本期订单到飞书”。再次修改后显示待同步，重新同步更新同一明细，不产生重复订单。

## 顾客入口

顾客首页：<http://127.0.0.1:3001/>，列出所有正在收集、尚未截单且未删除的团购期次。顾客选择一期进入商品页；只有一期时也保留列表。原来的 `/b/团购编号` 链接继续直接进入该期，已截单期次仍可查询订单。商品页的“全部团购”可返回首页重新选择。

## 下单与订单查询

同一手机号仅在同一期归为同一顾客，每次新提交表示补单追加，重复提交编号不会多下单。购物车按期次独立保存。整单通过数据库事务保存后立即显示成功，查询无需等待飞书。

下单成功后，手机号与姓名 / 群昵称保存在当前浏览器，跨期自动回填且可直接修改；修改后成功下单会更新记忆，备注不沿用。查订单页只预填上次下单手机号，仍需点击查询，查询其他号码不会更新记忆。待确认提交优先恢复原信息，清除记住的信息仅删除联系方式缓存，保留购物车与提交恢复记录。

## 顾客选品与自选清单

顾客选品页分为“精选好物”和“自选查询”两个页签，商品卡片默认展示图片、名称、商品说明和售价。自选查询使用团长固定的本期采购门店，查询结果可加入个人清单与购物车。同门店、同山姆商品编号且未分装的商品沿用后台售价和推荐费率，购物车合并数量；原整包与分装份作为不同商品，分别使用整包查询价格、自选费率及分装份价、推荐费率。来源缺货、停售或库存未知暂不阻止加购和登记订单，原始状态保留；仍需有效价格和完整商品资料，团长手动下架及本期截止等规则继续生效。

小屏幕选品列表采用左图、右侧商品信息与加购按钮的横向布局，大屏保留卡片网格。本期推荐、个人自选和查询结果随滚动分批显示，离屏商品回收后仍保留购物车数量；搜索覆盖完整本期商品。点击选品图片可查看大图，按关闭按钮、空白背景或 Escape 返回。山姆查询到当前结果末尾时自动加载下一页；查询失败后停止自动加载，可手动重试。

个人清单按期次和当前浏览器身份隔离，商品报价保存在服务器，购物车数量和身份保存在当前浏览器；刷新或服务重启可恢复。清除浏览器数据或换设备后，未提交清单不能自动恢复，已提交订单仍可用手机号查询。加入购物车时不改本期公共目录；正式下单后自选商品进入后台商品库与采购统计，标记为“顾客自选”。团长可核对后上架并选入本期推荐。

已保存的自选商品不按报价时间限制加购或下单，也不展示报价过期提示，清单与购物车沿用统一售价规则。服务器在提交时核对固定门店的实际价格、规格和本地设置，只有实际价格或规格等发生变化才更新个人清单并要求顾客确认；门店变化、团长手动下架或截单继续阻止提交。未加入个人清单的查询选择票据仍有 30 分钟有效期，并校验浏览器身份、期次与门店。自选订单保存已确认的商品报价与门店，不因后续商品编辑而改变历史金额。同款多次下单价格不同时，汇总显示“多次报价”，金额按各次实际报价计算。

## 截单与取消

删除商品项使用“已取消”状态保留同步关系；取消和缺货排除在有效采购数量与金额外。停止收集或达到截止时间后禁止新下单，仍允许查询。

## 删除与恢复期次

已截单期次可在“本期安排”点击“删除本期”并确认。删除采用可恢复方式：期次从正常列表和统计中隐藏，原收集链接停用，商品、历史订单、拼份记录及飞书备份关系保留。可在当前小区的“已删除期次”列表恢复；恢复后仍为已截单，需要主动编辑才能重新开放下单。已删除的期号不重复使用，删除全部期次后新建仍接着编号。正在同步本期订单或保存飞书配置时，需等待完成后再删除；已删除期次若有尚未确认的飞书新增记录，需先恢复该期并完成对账，才能切换订单导出表。

## 移除与恢复商品

商品库支持单件“移除”及勾选后“批量移除”，每次最多 200 件，确认后自动下架并从正常商品库和本期推荐页隐藏。在“已移除商品”中可以恢复，恢复后仍为待上架。移除保留历史订单、原价与定价规则、商品来源和期次关联，不改动已有订单或本期拼份记录；编辑原有期次时保留相关商品的历史关联，新建期次不能选入已移除商品。普通整包商品移除后，顾客仍可按本期自选机制查询同款并按新报价提交自选订单，不会自动恢复商品库记录；分装商品移除后不能继续追加原拼份商品，独立整包仍可查询和购买，其数量不计入分装成团。商品备份会保留这些商品，以“移除时间”文本字段记录状态，恢复后清空移除时间；飞书备份或配置保存进行中需等待完成后再移除。

## 手机访问与分享

在 `.env` 设置 `HOST=0.0.0.0` 后重启。手机连接同一 Wi-Fi，通过电脑局域网 IPv4 访问，例如 `http://192.168.1.100:3001/admin`。手机不能用电脑的 `127.0.0.1`，IP 可能随网络变化。

局域网监听时分享链接和二维码自动使用本机 IPv4。公网部署请配置 `PUBLIC_BASE_URL=https://你的域名`。公网部署、HTTPS 与微信实机兼容需要在可达地址下另外验证。

## 商品图片

山姆选品保存商品原图 URL，顾客页和后台优先显示此地址。图片目前备份的是 URL，不是图片文件；上游撤图会影响显示。旧商品仍按商品 ID 匹配，默认示意图地址为 `/images/{id}/cover.svg`。更换文件服务器时，在 `.env` 设置 `IMAGE_URL_TEMPLATE=https://你的文件服务器/products/{id}/cover.jpg` 后重启。缺图使用占位图。演示商品、报价和示意图仅供测试，正式使用前请替换。

## 服务说明与隐私

首页和各期页面的页脚明确显示代购用途、非官方商城关系与到货后付款，网页不在线收款；`/service.html` 与 `/privacy.html` 是无需 JavaScript 的公开说明页。下单填写区在输入前说明手机号用于费用核对，以及订单资料用于采购、分货、联系与查询。活动组织者的真实名称和联系方式需由运营者提供，并通过活动说明及原小区群公开，不虚构主体或资质。页面使用系统字体，不依赖外部字体服务。
